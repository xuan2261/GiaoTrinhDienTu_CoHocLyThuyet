# QA Gate Matrix

Each execution records one evidence record conforming to `data/schemas/evidence-registry.schema.json`. A `pass` status requires a capture bound to the complete gate definition, repository-state digest, declared-input hashes, artifact hash, timestamp and exit code. Public captures redact workstation paths, email addresses, IP addresses and credential-like values; review gates use restricted evidence classification. `not-run`, `fail`, and `blocked` state the observed condition rather than imply success. This matrix lists commands that exist now. It does not record a gate as having passed.
