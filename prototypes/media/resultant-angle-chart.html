Mục tiêu cục bộ: obj-ch1-resultant-angle

So sánh hợp lực khi góc thay đổi

Giữ F₁ = 80 N và F₂ = 60 N, sau đó đổi góc để đọc độ lớn đường chéo hình bình hành lực.

Biểu đồ R theo góc θ

R = 121.7 N

Đang dựng biểu đồ.

Bảng giá trị tĩnh

θR
0°140.0 N
60°121.7 N
90°100.0 N
120°72.1 N
180°20.0 N
R = √(F₁² + F₂² + 2F₁F₂ cos θ)

Tự kiểm: Dự đoán góc cho hợp lực lớn nhất và nhỏ nhất, rồi giải thích bằng hình bình hành lực.
